# MLT Lantern Test Simulator (RGY) – CDS Colour Vision Practice

A realistic web-based **MLT Lantern Test Simulator** designed for students and defence aspirants preparing for:

* Combined Defence Services (CDS)
* AFCAT
* NDA Medicals
* SSB Medical Colour Vision Screening
* Military & Aviation Colour Perception Tests

This simulator recreates the **Red-Green-Yellow (RGY) light discrimination test** commonly associated with lantern-based colour perception examinations.

---

## Preview

The application displays two coloured light dots for a short duration (1.5 seconds), after which the user must identify the colours shown on the left and right sides.

The simulator evaluates:

* Colour discrimination ability
* Accuracy
* Response consistency
* Speed-based performance

## How It Works

1. Press **Start**
2. Two coloured dots flash briefly
3. Dots disappear after 1.5 seconds
4. Select the colours you observed
5. Click **Next Set**
6. Complete all 9 sets
7. Receive final analysis and score

---

## Scoring System

The simulator calculates:

* Accuracy Score
* Time Taken
* Combined Performance Score

The final evaluation provides remarks such as:

## Recommended Practice Conditions

For better simulation accuracy:

* Sit approximately 50 cm away from the screen
* Use medium-to-high brightness
* Practice in a dimly lit room
* Avoid blue light filters/night mode
